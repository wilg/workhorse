# Commit (Cursor)

Read and follow the workflow defined in `COMMIT.md` in the same directory as this file.

## Cursor specifics

- Use Cursor's **Ask Questions** tool when possible to clarify commit scope — which logical change, include/exclude borderline files, staging vs drafting vs full commit.
- If the work involved broad agent edits, review the diff or restore from a checkpoint before committing so you only capture the intended logical change.
